##  Ziele
Ich will ein paar Dinge irgendwann machen, in ungefähr der Reienfolge in der ich sie aufliste. Diese Sachen werden auch in verschiedenen Fasen gemacht. 

# Fase 1: Grundlagen und einfacherere Projekte - RADAR, FPGA, Drohnen, Signaltechnik
1. Ein einfaches Program in Verilog schreiben.
2. Bad Apple auf einem Display mit einem FPGA abspielen.
3. Audioverarbeitung, oder FFT, oder Signalverarbeitung durch einen FPGA machen.
4. Einen einfachen RADAR oder LIDAR bauen.
5. Eine Drohne mit PID usw. bauen.
6. Eine Drohne mit RADAR oder LIDAR modul bauen.
7. Eine Dipolantenne bauen.
8. Eine Yagiantenne bauen.
9. Eine Parabolantenne bauen.
# Fase 1: Grundlagen und einfacherere Projekte - PCB, Chipdesign 
1. Ein paar gezielte PCBs für kleinere Projekte designen. - Sollte effektiv Teil anderer Punkte sein.
2. Einen eigenen Chip designen.
# Fase 2: Einen Schritt in richtung Produktion - Maschinen
1. Eine Lithografie Maschine bauen, egal wie schlecht sie sein wird
2. Entweder eine Maschine bauen oder erwärben die lokal PCBs herstellen kann.
3. Eine sehr gute Parabolantenne bauen. 
4. Eine Bodenstation.
5. Eine gute FPV Drohne.
6. Eine Drohne die 250 km/h oder schneller fliegt.
7. Einen Klystron bauen.
# Fase 3: Einen Schritt in richtung Produktion - Verbesserte Maschinen
1. Eine Lithografie Maschine bauen die ein schwereres Konzept verwirklicht, ob es ein Nachbau der Stempel von Canon ist, oder das EUV von Zeiss und ASML.
2. Einen Qualitätsklystron herstellen.
